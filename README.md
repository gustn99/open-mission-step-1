# open-mission-step-1

## 🎯 미션 개요

- 기존 CLI 기반 로또 프로그램을 객체지향 원칙에 따라 재구성한다.
- 새로 작성한 코드를 바탕으로 웹(바닐라 JS) 환경에서 동작하도록 마이그레이션한다.

## 🚀 실행 방법

```bash
# 의존성 설치
npm i

# cli
npm run cli

# web
npm run web
```

## 🧭 미션 목표

- 객체지향 설계(OOP)가 코드의 변화(입출력 환경 변경 등)에 어떻게 대응하는지를 경험한다.
- 프론트엔드 개발 맥락에서 객체지향 설계가 가지는 의미와 한계를 검토한다.

## 📋 미션 요구사항

- 기존 CLI 프로그램의 비즈니스 로직 코드는 그대로 유지한다.
- DOM 조작, 이벤트 핸들링 등 입출력 관련 부분은 변경 가능하다.
- UI 구성은 자유지만, 동작 흐름이 CLI 버전과 동일해야 한다.
